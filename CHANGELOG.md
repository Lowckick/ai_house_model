# Історія змін

Версії позначають етапи роботи; моделі зберігаються незмінними для відтворюваності.

## 3.0 — 19.11.2026: панель, демо-режим і оформлення

- Вебпанель «Панель мікроклімату»: п'ять вкладок, світла й темна теми, винесені й
  відформатовані CSS/JS, сувора політика безпеки вмісту (без вбудованих скриптів).
- Демо-режим `web --demo`: доба показників двох симульованих кімнат, імпорт і порівняння.
- Графіки результатів (`figures`), сторінка [docs/results.md](docs/results.md), новий README,
  індекс документації, нотатки для розробника.
- Ліцензія MIT, `pyproject.toml`, лінтер ruff у CI, docstrings для публічного API,
  тест відтворюваності опублікованих результатів; артефакти першої версії — у `data/legacy/`.

## 2.3 — 18.11.2026: адаптація до різних будинків

- Варіанти будинку: реалістичний CO₂, погана ізоляція, інерційне опалення, добові розклади мешканців.
- Команда `adapt`: правила, перепідібрані перебором, проти мережі без і з перенавчанням.
- Результат: мережа краща за перепідібрані правила в 192 з 200 сценаріїв ([adaptation.md](docs/adaptation.md)).

## 2.2 — 18.11.2026: живі датчики, погода, калібрування

- Тіньовий режим: `POST /api/live/<кімната>`, MQTT, тривоги (браузер, Telegram), `shadow-report`.
- Погодинна погода Open-Meteo для показників; команда `calibrate` і ключ `--physics`.
- Docker-образ і compose-файл; GitHub Actions.

## 2.1 — 18.11.2026: двозонний тариф і `rules_v2` — модель `rollout-v3-tou`

- Винагорода `comfort_safety_tou_v3`, вартість у гривнях у всіх порівняннях.
- Нічний режим більше не охолоджує спальню нижче 23 °C (`rules_v2`).
- `rollout-v3-tou`: на 3–5 % дешевша за `rollout-v2` при майже тому ж комфорті.

## 2.0 — 17.11.2026: rollout-навчання — модель `rollout-v2`

- Діагностика: DQN-модель у всіх 16 128 рішеннях повторювала контролер.
- Посилений базовий контролер `residual_v2`; мітки перебором корекцій на копії симулятора,
  дистиляція в мережу, DAgger; обмеження монотонності корекцій.
- `rollout-v2`: комфорт 93,8 % проти 92,2 % у посиленого контролера, −1 кВт·год/добу.
