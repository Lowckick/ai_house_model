# Навчені моделі

## `rollout-v2.pt` — рекомендована

Політика `residual_v2`: 19 корекцій над сильнішим ступінчастим контролером,
навчена методом `rollout` (оцінки корекцій на копії симулятора, дистиляція
в мережу, DAgger, відбір лише на validation). Під час роботи потрібна лише мережа.

```bash
python main.py web --model data/models/rollout-v2.pt
```

На 40 test-сценаріях (seed 20000 і 31000) порівняно з сильним контролером:
комфорт +1.7 в.п., енергія −1 кВт·год/добу, винагорода +14.5, небезпечні кроки
без змін; порівняно з `improved-v2.pt`: комфорт ≈93.8 % проти 83–84 %,
небезпечних кроків приблизно на 45 % менше, енергії +3.1–3.7 кВт·год/добу.
[Методика та результати](../../docs/training-results.md#експеримент-rollout-17-листопада-2026).
`rollout-v2-evaluation.json` — повний звіт експерименту.

SHA-256 checkpoint: `fd5cc0563ee2b9ab8b184acddfa05cff3956ca102e091ccdf00e7f108b218127`.

## `improved-v2.pt` — попередня гібридна політика

`improved-v2.pt` — checkpoint, відібраний лише за validation у виконаному
експерименті з seed 42, 43, 44, по 30 RL-епізодів і 12 експертних епізодів.
Політика `residual_v1` використовує 19 корекцій над детермінованим контролером.

```bash
python main.py web --model data/models/improved-v2.pt
```

`improved-v2-evaluation.json` — повний звіт експерименту. Шляхи всередині
нього позначають початковий локальний запуск; опублікований checkpoint
скопійовано без змін у цей каталог. Сирі SQLite-бази та інші проміжні
артефакти в Git не включені. Початкову `data/model.pt` збережено.

На 12 test-сценаріях комфорт становив 84.55% проти 57.83% у старої моделі;
споживання — 23.90 проти 16.78 кВт·год. Нова політика відтворює простий
контролер: RL не перевершив його, тому відібрано checkpoint після warmup.
[Методика та результати](../../docs/training-results.md).

SHA-256 checkpoint: `c57f75d2594db8b7d9499a17e12d76f51a56155945c36dc1734d2ffb817ebd43`.
