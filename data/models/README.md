# Навчена гібридна політика

`improved-v2.pt` — checkpoint, відібраний лише за validation у виконаному
експерименті з seed 42, 43, 44, по 30 RL-епізодів і 12 експертних епізодів.
Політика `residual_v1` використовує 19 корекцій над детермінованим контролером.

```bash
python main.py web --model data/models/improved-v2.pt
```

`improved-v2-evaluation.json` — повний звіт експерименту. Шляхи всередині
нього позначають початковий локальний запуск; опублікований checkpoint
скопійовано без змін у цей каталог. Сирі SQLite-бази та інші проміжні
артефакти в Git не включені. Початкову `data/model.pt` збережено.

На 12 test-сценаріях комфорт становив 84.55% проти 57.83% у старої моделі;
споживання — 23.90 проти 16.78 кВт·год. Нова політика відтворює простий
контролер: RL не перевершив його, тому відібрано checkpoint після warmup.
[Методика та результати](../../docs/training-results.md).
