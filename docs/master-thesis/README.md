## Статус

Повний змістовий проєкт для перевірки керівником. Натурні результати фізичних датчиків очікуються: для них залишено підрозділ 5.8 і додаток Д. Дати, підписи, погодження та оцінки не вигадані. Презентації, усні виступи й захист до пакета не включені.

Симуляційний експеримент не встановив переваги гібридної політики над детермінованим контролером. Цей результат збережено у висновках. Пакет містить протокол 26 успішних тестів і первинні результати.

DOCX має стилі Times New Roman 14 pt. PDF створено у середовищі з метрично сумісним Liberation Serif; перед остаточним поданням слід звірити оформлення в Word, повторно експортувати PDF та оновити зміст після доповнень.

Матеріали опубліковано в окремій гілці; вихідна гілка `main` не змінюється.
