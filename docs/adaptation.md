# Адаптація до різних будинків: правила проти нейромережі

Питання: чи дає нейромережа щось понад добре налаштовані правила, коли будинок
відрізняється від того, під який усе налаштовували? П'ять варіантів будинку
(`smart_house/environment/houses.py`), однакові винагорода `comfort_safety_v2`,
правила `rules_v2` і сценарії:

| Будинок | Що змінено |
| --- | --- |
| `default` | симулятор усіх попередніх експериментів |
| `realistic_co2` | людина додає 250 ppm CO₂/год (а не 20), є природний повітрообмін 0,5/год |
| `poor_insulation` | тепловтрати 0,14/год замість ≈0,093: у морози навіть сильний обігрів ледве встигає |
| `lagged_schedule` | інерційне опалення (тепла підлога, стала часу 1,5 год) і сталі добові розклади мешканців |
| `combined` | усе разом + швидший обмін вологою |

Для кожного будинку порівнюються чотири політики:

- **пороги типові** — посилений ступінчастий контролер, налаштований під `default`;
- **пороги перепідібрані** — ті самі правила з порогами, підібраними для цього будинку
  перебором 540 комбінацій на 12 validation-сценаріях (замінник ручного налаштування інженером);
- **мережа з типового** — rollout-мережа, навчена на `default`, без перенавчання;
- **мережа перенавчена** — той самий автоматичний конвеєр, навчений на цьому будинку.

Відбір порогів, checkpoint і seed — лише на validation. Потім один раз — парна оцінка
на test (seed 20000 і 31000, по 20 сценаріїв). Навчання: seed 42 і 43, 3 раунди × 48
сценаріїв. Відтворення (≈40 хв на будинок, продовжується з місця зупинки):

```bash
python main.py adapt --output-dir data/user/training/adaptation-01
```

Повний звіт: [`results/adaptation-2026-11-18.json`](results/adaptation-2026-11-18.json).

## Висновки

1. Перенавчена мережа краща за найкращі підібрані правила в кожному будинку: +8…+15
   винагороди, +0,8…+1,7 в.п. комфорту, у 192 зі 200 парних сценаріїв; енергія в
   середньому та сама або нижча (−1,75…+0,53 кВт·год); більше небезпечних кроків — у жодному.
2. Мережа переноситься: навіть без перенавчання вона випереджає типові правила на +12…+20
   і перепідібрані правила — у всіх будинках. Відрив від типових правил більший у складніших
   будинках (погана ізоляція, інерція), ніж у типовому.
3. Перенавчання мало що дає в простих варіантах, але найбільше — у найскладнішому
   (`combined`, +3,5…+5,1): що далі будинок від навчального, то корисніше адаптуватись.
4. Перепідбір порогів купує комфорт ціною енергії (+0,75…+1,58 кВт·год у всіх чотирьох
   нетипових будинках), а мережа досягає більшого комфорту без цієї ціни.
5. Перепідбір правил — це 540 оцінок і вибір сітки людиною; конвеєр мережі автоматичний.

Обмеження: усе це варіанти одного спрощеного симулятора; `nn_default` в одному сценарії
кожного test-набору будинку `combined` мав на 1 небезпечний крок більше за типові правила
(83 проти 82 і 58 проти 57; перенавчена мережа — ні). Мережа має той самий базовий контролер (`residual_v2`),
тож перевага — це корекції понад правила, а не заміна правил.
