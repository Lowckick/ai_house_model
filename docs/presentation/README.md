## Відповідність наданому плану

| Слайд | Зміст |
| --- | --- |
| 1 | Тема, автор і керівник |
| 2 | Актуальність роботи |
| 3 | Об’єкт дослідження |
| 4 | Предмет дослідження |
| 5 | Постановка задачі |
| 6 | Запропоноване рішення |
| 7 | Результати проведених досліджень |
| 8 | Розробка програмного забезпечення |
| 9 | Результати тестування |
| 10 | Висновки |

Кожен із дев’яти критеріїв семінару має окремий слайд і йде в наданому порядку. Окремий слайд подяки вилучено. Новизну збережено на слайді 4: адаптація гібридної політики та її порівняння з детермінованою системою. Останній слайд містить висновки й подальші кроки.

Виступ переписано під цей порядок: **750 слів, приблизно 6–7 хвилин**, орієнтовний план 6 хв 20 с. Для кожного слайда наведено текст, часовий орієнтир і підказку, що показати. У Word/PDF — три сторінки; текст кожного слайда збережено разом. У Markdown є порада щодо скорочення. Повний текст також вбудовано в нотатки PowerPoint, окремо від технічної довідки.

## Узгодженість із магістерською

Використано [оновлену чернетку магістерської](https://github.com/Lowckick/ai_house_model/tree/docs/master-thesis-2026-10-26/docs/master-thesis), коміт `0a79f0b10ff0d9a9d6f3bfd2f924cf643469a701`. Метод — дистиляція політики від модельного планувальника, checkpoint `planned-v1.pt`. Успіх онлайн-RL не заявляється.

Слайд 7: одна незмінна модель, 60 парних добових сценаріїв, комфорт +3,11 відсоткового пункта, кроки поза межами −16,80%, енергія +3,57%. Комфорт вищий у 34 сценаріях, нижчий у 26. Це середній компроміс симулятора, а не універсальна перевага.

Слайд 9: 28 автоматизованих тестів і сім предметних перевірок пройдено; три незалежні навчальні запуски мають власний validation-відбір. Вони оцінювалися на спільних 20 сценаріях і не додаються до 60 канонічних епізодів. Сервісні затримки 2,258 і 1,306 мс — актуальний замір із новим checkpoint, по 40 викликів, із SQLite та без HTTP. Це інший вимір, ніж час ядра мережі.

Фізичні датчики наявні, але їхній збір і натурний аналіз не завершено. Натурних числових результатів у презентації немає. Новизна є прикладним методичним внеском цієї роботи; світова першість не заявляється.
