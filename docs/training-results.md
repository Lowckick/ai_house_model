# Перевірений експеримент 23 жовтня 2026

Команда виконана в підготовленому середовищі на CPU з 2 потоками:

```bash
python main.py train --no-ui --seeds 42 43 44 --episodes 30 \
  --warmup-episodes 12 --warmup-epochs 5 \
  --validation-interval 5 --validation-episodes 6 --test-episodes 12 \
  --reference-model data/model.pt \
  --output-dir data/user/training/improved-v2-20261023
```

90 RL-епізодів сумарно, 36 експертних епізодів. Для кожного seed
checkpoint відібрано за 6 validation-сценаріями. Після вибору проведено
оцінку на тих самих 12 test-сценаріях для кожної моделі та старого checkpoint.

Середні значення за test-епізодами, кожен по 144 кроки:

| Метрика | Стара модель | Нова гібридна політика | Простий контролер |
| --- | ---: | ---: | ---: |
| Комфорт, % | 57.83 | 84.55 | 84.55 |
| Енергія, кВт·год | 16.78 | 23.90 | 23.90 |
| Винагорода v2 | −104.14 | 155.73 | 155.73 |
| Кроки поза безпечними межами | 8.50 | 4.08 | 4.08 |

Нижче споживання старої моделі супроводжується нижчим комфортом та більшою
кількістю небезпечних кроків. Нова політика **не перевершила простий контролер**:
для всіх трьох seed найкращим за validation залишився checkpoint після
експертного warmup (`best_episode=0`). Відбір відкинув гірші RL-ітерації.
Тестові метрики між seed збігаються, оскільки обрані політики відтворюють
рішення вчителя; це не доводить незалежного покращення від RL.

Вибрано seed 42 через рівність validation-метрик та стабільний порядок seed.
Checkpoint у поточному середовищі:
`data/user/training/improved-v2-20261023/best.pt`.
Повний звіт: `data/user/training/improved-v2-20261023/experiment.json`.
Для кожного seed збережено і `last.pt`, щоб можна було дослідити подальшу поведінку RL.
Артефакти в `data/user/` локальні й виключені з Git; переносіть їх окремо
або відтворюйте експеримент. Початкова `data/model.pt` не змінена.

Перевірено 19 автоматизованих тестів, імпорт із новою моделлю,
генерацію знімка/навчального звіту та браузерний сценарій: завантаження,
перевірка, рекомендації, пояснення, експорт, історія, оцінка й мобільний вигляд.

Подальша робота над якістю RL потребує окремого експерименту зі збереженням
цього test-набору як звітного, без підбору гіперпараметрів за його результатами.
Порівняння стосується спрощеного симулятора, а не виміряної економії будинку.

Опубліковані копії вибраного checkpoint і звіту доступні в
[`data/models/`](../data/models/README.md). Після клонування запускайте
`python main.py web --model data/models/improved-v2.pt`.
